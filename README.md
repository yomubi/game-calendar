# Game Calendar

ICS calendar feeds for Japanese mobile games. Currently testing **Fate/Grand Order** and **Iris Mysteria**.

## How to use

Pick a feed URL below, then add it to your calendar app as a **subscribed calendar**.

- **iOS** — Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar
- **Google Calendar** — Other calendars → From URL

### Fate/Grand Order

https://yomubi.github.io/game-calendar/fgo_jp.ics

### Iris Mysteria
